# v0.1：繁體台灣術語 mdBook 初版

## 版本目標與範圍

從原始 EPUB 建立首個獨立、可離線閱讀的 mdBook HTML 電子書。前一版為未轉換的 EPUB，沒有 mdBook 專案。

## 變更項目

- 新增：按 OPF 順序的 Markdown 章節、SUMMARY、圖片、首頁、book.toml、Makefile、test.sh、轉換程式、術語表與檢查報告。
- 修改：正文改為繁體台灣慣用術語；程式碼與技術識別字保持來源內容。
- 移除：無；原始 EPUB 保留於 `source/original.epub`。

## 測試與驗收標準

依 `plan.md`：104 個內容檔與 176 張圖片完整；單元與系統測試、`mdbook build`、離線連結與搜尋、`make clean && make build` 均通過。

## 風險、相容性與回滾

- 來源有疑似 OCR 錯字及原先簡轉繁留下的詞彙；自動轉換不能保證語義全對，未確定項目需列入報告供人工確認。
- 原 EPUB 的複雜 HTML、表格或 CSS 可能無法一比一呈現；以文字、程式碼、圖表及閱讀順序完整為優先。
- HTML 為靜態產物，支援本地瀏覽器離線閱讀。可刪除生成的 `src/chapters/`、`src/images/`、`book/`，再由保存的 EPUB 重建；原檔不改動。
