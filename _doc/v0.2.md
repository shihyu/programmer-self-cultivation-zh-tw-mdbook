# v0.2：GitHub Pages 發布

## 版本目標與範圍

在 v0.1 的本地離線 mdBook 基礎上，新增可重複執行的 GitHub Pages 發布流程。書籍轉換與內容保持 v0.1 的產出。

## 變更項目

- 新增：`make publish`、`scripts/publish_pages.py`、本機 Git 分支發布測試與 GitHub Pages 使用說明。
- 修改：Makefile help、README 與系統測試，確保先建置和測試才推送 HTML。
- 移除：無；`book/` 為可重建產物，不納入 `main`，發布於 `gh-pages` 分支。

## 測試與驗收標準

- `make test` 的單元與系統測試通過；本機 bare Git repo 測試確認首次與再次發布均能推送 HTML，且分支只含網站產物與 `.nojekyll`。
- `make publish` 先編譯並測試，再推送 `gh-pages`；GitHub Pages 來源設為該分支根目錄。
- 線上首頁與至少一個章節回傳 HTTP 200，圖片與搜尋可用。

## 風險、相容性與回滾

- 公開 GitHub repo 和 Pages 會讓全文與圖片可被任何人讀取；公開發布前須確認擁有再散布權利。
- Pages 可能在推送後短暫等待部署，需檢查 Pages 狀態與線上 URL。
- 回滾可將 `gh-pages` 分支推回上一個提交；原始 EPUB 和 `main` 的 mdBook 來源不受發布分支影響。
